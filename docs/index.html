Our Engineering Playbook

A lightweight engineering baseline for individuals and small teams building software with AI—not an enterprise governance framework.

Current release: v1.0.0 (source tag). Use the installers in the tagged tree; this release does not attach separate archives.

Install the repository, then adapt its specifications, agent instructions, deterministic verification, security controls, and evaluation criteria to your own architecture. It is designed to be fast to adopt and inexpensive to operate before a team has dedicated platform or security functions.
