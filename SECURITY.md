# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, exposed credential, unsafe installer behaviour, or supply-chain concern. Use GitHub's private vulnerability reporting for this repository when available, or contact the repository owner through the verified channels on [otrobonita.com](https://www.otrobonita.com/).

Include the affected revision, reproduction steps, potential impact, and any safe evidence you can share. Do not include live secrets or personal data.

## Scope

The playbook is a configurable foundation, not a security product or guarantee. Teams remain responsible for adapting its policies, permissions, controls, evaluations, and release checks to their own system and threat model.
